# 🌏 상해 AWE 2026 참관단 안내 시스템

> 중국 상하이 AWE 2026 박람회 해외출장 단체 참관을 위한 공지사항 안내 웹앱

---

## 📌 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **행사명** | 상해 AWE 2026 참관 |
| **장소** | 중국 · 상해 (CIIE 신국제박람중심) |
| **일정** | 2026. 3. 12 (목) ~ 3. 17 (화) |
| **대상** | 책임자급 (임원), 실무자급 (직원) |

---

## ✅ 구현 완료 기능

### 🖥️ 1페이지 - 메인 랜딩
- 배경: 딥 네이비 + 별 반짝임 애니메이션
- **상해 AWE 2026** 타이틀 대형 표기
- 행사 일정, 장소 정보 표시
- **책임자급 / 실무자급** 선택 버튼 (각각 다른 안내 페이지로 이동)
- 부드러운 페이드 전환 효과

### 📋 2페이지 - 안내 페이지

#### 🔝 헤더
- 좌측 상단: `상해 AWE 2026 참관 (책임자급/실무자급)` 표기 (클릭 불가)
- 우측 상단: 사용자/관리자 아이콘 전환
  - **사용자 모드**: 조회만 가능, 편집 기능 숨김
  - **관리자 모드**: 비밀번호 `0000` 입력 후 전환, 편집 기능 표시
- **[처음으로] 버튼**: 랜딩 페이지로 복귀

#### 📂 6개 메뉴 탭

| 메뉴 | 내용 |
|------|------|
| **중요 안내사항** | 중요 안내 (강조 카드) + 기본 안내 (스태프 연락처, 준비물, 날씨) |
| **방문기업 정보** | 자유 텍스트 편집 |
| **학습자료** | 파일 업로드/다운로드 + YouTube 영상 썸네일 |
| **참가자명단** | 파일 업로드 (PDF/이미지/엑셀/워드) |
| **일정표** | 파일 업로드 (PDF/이미지/엑셀/워드) |
| **방 배정표** | 파일 업로드 (PDF/이미지/엑셀/워드) |

#### 🌤️ 날씨 위젯
- **베이징 + 상하이** 실시간 날씨 (Open-Meteo API)
- 현재 온도, 날씨 상태, 습도, 바람 표시
- **7일 주간 날씨** (최저/최고 온도, 날씨 아이콘)
- 새로고침 버튼 지원

#### 🔐 관리자 기능
- 비밀번호: `0000`
- 중요 안내 텍스트 편집
- 준비물 목록 편집
- 스태프 연락처 추가/편집/삭제
- 방문기업 정보 편집
- 파일 업로드 (최대 10MB, PDF/이미지/엑셀/워드)
- 파일 삭제
- YouTube URL 등록 (자동 썸네일 미리보기)
- **저장 시 "수정하시겠습니까?" 확인 창** → 최종 확인 후 저장

## 🗄️ 데이터 모델

### `awe_content` - 텍스트 콘텐츠
| 필드 | 타입 | 설명 |
|------|------|------|
| id | text | 고유 ID |
| user_type | text | `executive` / `staff` |
| menu | text | 메뉴 키 |
| section | text | 섹션 (important, prep, main 등) |
| title | text | 항목 제목 |
| content | rich_text | 실제 내용 |
| sort_order | number | 정렬 순서 |

### `awe_files` - 파일/링크
| 필드 | 타입 | 설명 |
|------|------|------|
| id | text | 고유 ID |
| user_type | text | `executive` / `staff` |
| menu | text | 메뉴 키 |
| file_name | text | 파일명 또는 YouTube 제목 |
| file_type | text | `pdf`, `image`, `excel`, `word`, `youtube` |
| file_data | rich_text | Base64 데이터 또는 YouTube URL |
| file_size | text | 포맷된 파일 크기 |
| thumbnail_url | text | YouTube 썸네일 URL |
| sort_order | number | 정렬 순서 |

### `awe_contacts` - 스태프 연락처
| 필드 | 타입 | 설명 |
|------|------|------|
| id | text | 고유 ID |
| user_type | text | `executive` / `staff` |
| name | text | 이름 |
| role | text | 역할 |
| phone | text | 연락처 |
| sort_order | number | 정렬 순서 |

## 🚀 사용 방법

### 사용자
1. `index.html` 접속
2. **책임자급** 또는 **실무자급** 선택
3. 각 메뉴 탭에서 안내사항 확인
4. 파일 다운로드, YouTube 영상 재생 가능

### 관리자
1. 안내 페이지 우측 상단 ⚙️ 아이콘 클릭
2. 비밀번호 `0000` 입력
3. 원하는 메뉴에서 **편집** 버튼 클릭
4. 내용 수정 후 저장 → "수정하시겠습니까?" 확인
